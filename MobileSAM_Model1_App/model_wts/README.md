# Model weights

Put these exact files in this folder:

```text
model_wts/
├── mobile_sam.pt
├── mobileclip_s0.pt
└── lama_fp32.onnx
```

Sources:

- MobileSAM: https://github.com/ChaoningZhang/MobileSAM

- LaMa ONNX: https://huggingface.co/Carve/LaMa-ONNX/blob/main/lama_fp32.onnx
